# Glossy Native Sound Effects Pack

This build extends the native Float32 DSP path with spatial/crossfeed/reverb effects adapted from the supplied SuV Music source tree.

## Native effects
- Spatial Wide: ITD/ILD-inspired stereo spatialization
- 3D Space: spatial width + light ambience
- Live Stage: wider field + room ambience
- Cinema Surround: cinematic width + controlled ambience
- Studio Width: restrained widening
- Headphone Space: spatialization + crossfeed
- Natural Crossfeed: short-delay low-pass interaural mixing
- Deep Space: bass + spatial field + ambience
- Air & Space: high-frequency lift + spatial field
- Gaming Immersive: wider field + spatial cues
- Night Spatial: restrained spatial processing
- Mono-Safe Space: conservative spatial width

All effects run before the final safety limiter. Presets are device-agnostic; actual headphone/speaker response varies by hardware.

## Source / license note
The spatial/crossfeed processing concepts were adapted from the SuV Music project supplied in the conversation. The supplied project is GPL-3.0 licensed; this project already carries GPL-3.0 licensing.

No proprietary commercial audio samples are bundled. These are algorithmic DSP effects, not copied audio recordings.
